Building Static Sites with SSG

Home Gallery Blogs About me

A modern static site generator that uses CSS selectors for content injection. No custom templating language required - just HTML, CSS, JavaScript, and YAML. This approach lets you use standard web technologies you already know.

Key Features:

  • Real HTML/CSS/JS Templates - Work with standard web technologies
  • YAML content files - Clean, readable content format with front-matter
  • CSS selector-based injection - Map content to elements using selectors
  • Markdown support - Write blog posts in markdown
  • Full blog features - Tag pages, RSS feed, sitemap, pagination
  • Live reload dev server - Watch mode with auto-rebuild
  • Fast builds - Efficient rendering with JSDOM
Installation

Install from npm or source:

# Install from npm
npm i selector-ssg

# Install from source
npm install
npm link

Getting Started

Initialize a new project:

ssg init

# Initialize with specific directory
ssg init -d my-project

Start development server:

ssg serve

# Custom port
ssg serve --port 8080

# Without watch mode
ssg serve --no-watch

Build your static site:

ssg build

# Custom configuration
ssg build --config custom-config.yml

# Verbose output
ssg build --verbose

Configuration

Edit config.yml to customize your site:

site:
  name: My Site
  url: https://example.com
  language: en

paths:
  template: template
  source: source/public
  dist: dist

build:
  clean: true
  pretty_urls: true  # /about/ vs /about.html
  strict_selectors: false  # Fail on missing selectors

blog:
  posts_dir: blog
  index_layout: page
  index_slug: blog
  posts_per_page: 10

Creating Content

Create a new page or post:

ssg new post "My Post Title"
ssg new page "About Us"

YAML Content Format

type: page
layout: page
title: About
slug: about

inject:
  "h1": title
  ".content": body_html

body:
  format: markdown
  content: |
    # About Us
    
    Your content here...

CSS Selector Injection

Map YAML fields to HTML elements using CSS selectors:

type: post
layout: post
title: My First Post
slug: my-first-post
date: 2025-01-01
tags: [tech, tutorial]
draft: false

inject:
  "h1.title": title
  ".post-meta .date": date
  ".content": body_html

body:
  format: markdown
  content: |
    # Hello World
    
    This is my blog post...

Set attributes using @ notation:

inject:
  "h1": title  # Set text content
  ".hero-image@src": image_url  # Set attribute
  ".content": body_html  # Set HTML content
  "meta[name='description']@content": excerpt

Using data-bind Attributes

Add data-bind attributes to your HTML templates:

<h1 data-bind="title">Fallback Title</h1>
<div data-bind="body_html"></div>
<time data-bind="date"></time>

The YAML values will automatically populate these elements.

Layouts

Layouts are regular HTML files in template/layouts/:

<h1>Site Title</h1>

<span>Site Title</span>

Partials

Include reusable components using <include>:

<span></span>

Body Content Formats

Markdown format:

body:
  format: markdown
  content: |
    # Heading
    
    Paragraph with **bold** and *italic*.

HTML format:

body:
  format: html
  content: |
    Heading
    Your HTML content...

Text format:

body:
  format: text
  content: Plain text will be escaped

Automatic Features

The generator automatically creates:

  • Blog index - List of all posts at /blog
  • Tag pages - Individual pages for each tag at /tags/{tag}
  • RSS feed - XML feed at /rss.xml
  • Sitemap - SEO sitemap at /sitemap.xml

Automatic Fields

These fields are automatically generated:

  • body_html - Rendered HTML from body content
  • excerpt - Auto-generated excerpt from markdown (first 200 chars)
  • reading_time - Estimated reading time in minutes

Custom Fields

Add any custom fields to your YAML:

title: My Post
author: John Doe
hero_image: /img/hero.jpg
cta_text: Learn More
cta_url: /signup

inject:
  ".author": author
  ".hero@src": hero_image
  ".cta": cta_text
  ".cta@href": cta_url
Development Workflow

The dev server watches for changes in:

  • source/public/ - Content files
  • template/ - Templates, layouts, partials, assets

Changes trigger automatic rebuild.
